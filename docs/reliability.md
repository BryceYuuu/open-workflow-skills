# Reliability model / 真实性与质量模型

## Production Ready

The underlying technical stack is mature enough for repeatable use when dependencies are present.

This label does **not** guarantee every output is correct. Validation remains required.

## Integration Required

The workflow is real, but depends on external APIs, Apps, OAuth, browser sessions, data sources, accounts, or infrastructure.

A SKILL.md cannot manufacture those permissions.

## Experimental / Assisted

The workflow is technically feasible, but one or more of these applies:

- subjective creative quality
- generative consistency issues
- difficult real-time constraints
- incomplete source information
- forecasting uncertainty
- domain judgment
- environment-specific behavior

Outputs should be treated as candidates or assistance rather than guaranteed outcomes.
